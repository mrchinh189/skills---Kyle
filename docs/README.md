# Tài liệu BA — Agent Skills cho ứng dụng doanh nghiệp

Thư mục này chứa tài liệu giúp bạn (Agentic AI BA + IT BA) **hiểu cốt lõi** kho Agent Skills và
**vận dụng** nó vào công việc phân tích nghiệp vụ.

## Đọc theo thứ tự

1. **[01 — Hướng dẫn trực quan Agent Skills](./01-agent-skills-huong-dan-truc-quan.md)**
   Giải mã triết lý & kiến trúc repo gốc: skill là gì, progressive disclosure, cơ chế trigger, vòng
   lặp tạo skill, triết lý viết, catalog 17 skill — kèm sơ đồ Mermaid.

2. **[02 — Playbook bộ skill BA](./02-ba-skills-playbook.md)**
   Ánh xạ vòng đời dự án BA vào 7 skill `ba-*`: khi nào dùng, đầu vào/đầu ra, prompt mẫu, kịch bản
   ghép skill, cách phối hợp với skill gốc.

## Bộ skill BA đi kèm (trong `../skills/`)

| Skill | Vai trò |
|---|---|
| `ba-elicitation` | Khơi gợi yêu cầu (phỏng vấn, workshop, khảo sát) |
| `ba-requirements-spec` | Đặc tả BRD / SRS / FRD / NFR |
| `ba-user-stories` | Epic, user story, tiêu chí chấp nhận (Gherkin), INVEST |
| `ba-process-modeling` | Mô hình hoá quy trình AS-IS/TO-BE (Mermaid) + gap analysis |
| `ba-stakeholder-mgmt` | Bản đồ stakeholder, RACI, kế hoạch truyền thông, status 3P |
| `ba-solution-validation` | Ma trận truy vết (RTM), UAT, gap analysis, nghiệm thu |
| `ba-ai-usecase` | Đánh giá & định hình use-case AI/Agentic AI có trách nhiệm |

> Sơ đồ Mermaid trong các tài liệu này render trực tiếp trên GitHub. Nếu xem bằng trình đọc Markdown
> khác mà không thấy sơ đồ, hãy bật plugin hỗ trợ Mermaid.
